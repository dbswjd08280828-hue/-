## 2. 상위노출 구조 요약 (행궁동/대전/강릉 카페 상위노출 글 3건 분석 결과)

- **9단 구조**: 제목 → 인사·도입(키워드1회) → 정보블록(지도+상호/주소/시간/휴무/전화/주차) → 접근성 → 공간 동선(외관→포토존→좌석) → 메뉴/가격 리스트 → 신뢰신호(원산지·수제 등) → 주문내역+시식평 → 총평(불릿)+마무리(추천대상+키워드 재언급)
- **제목 공식**: `[지역/동네] + [업종키워드] + 가게명 + 차별점` — 키워드는 항상 제목 앞쪽, 가게명 필수 노출
- **키워드 배치**: 제목·도입·본문중간·마무리 4곳에 자연스럽게 4~6회 (스터핑 금지)
- **AI 인용 최적화**: 정보블록은 key-value 구조로(이모지 라벨), 메뉴/가격은 리스트 형태로, 총평은 3~5줄 불릿(TL;DR 역할), "누구에게 추천하는지" 명시 문장 포함
- **신뢰 신호**: 원산지 표시, 당일생산/수제, 실제 주문내역 명시, 오감 표현+비교급("이제껏 먹어본 것 중 가장 ~")
